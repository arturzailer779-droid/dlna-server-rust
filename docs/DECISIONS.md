# Архитектурные решения

## ADR-001 — Собственная реализация
Новый проект не является форком старого приложения и не использует MiniDLNA как движок. Старый репозиторий — только справочный материал.

## ADR-002 — Rust + Slint
Rust для ядра и приложения; Slint для GUI. Один общий core для Linux и Windows.

## ADR-003 — Direct Play по умолчанию
Оригинальный файл передаётся без изменения; телевизор декодирует его самостоятельно.

## ADR-004 — Транскодирование опционально
Транскодер изолирован, выключен по умолчанию и не является зависимостью основного ядра. Конкретный движок требует отдельного решения.

## ADR-005 — Осторожное определение возможностей ТВ
Не считать User-Agent или производителя достоверным полным перечнем кодеков. Хранить источник и степень достоверности сведений.

## ADR-006 — Linux first, Windows next
Платформенные функции отделены от общего ядра.

## ADR-007 — Никаких фиктивных функций
UI-команда должна быть связана с реальной функцией. Неиспользуемые заглушки не выдаются за готовую реализацию.
