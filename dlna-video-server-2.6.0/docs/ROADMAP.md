# План разработки

1. Foundation: workspace, сборка, ошибки, конфигурация, журналирование, модель состояния.
2. UI integration: Slint подключён к реальному Application Controller.
3. Media Library: корневые папки, сканирование, индекс, обновление.
4. Network: интерфейсы, IP, жизненный цикл сетевых задач.
5. DLNA discovery: SSDP и описание устройства.
6. DLNA control: SOAP, ContentDirectory, DIDL-Lite, ConnectionManager.
7. Streaming: HTTP GET/HEAD, Range/206, безопасность путей, параллельные клиенты.
8. Client compatibility: профили, источники данных, ручные переопределения.
9. Linux packaging: установка, трей, автозапуск, Anti-Sleep.
10. Optional transcoding: только после отдельного утверждения движка и тестовой матрицы.
11. Windows adapter and packaging.
12. Реальная проверка на телевизорах и регрессионная приёмка.
