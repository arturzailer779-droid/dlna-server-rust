# Архитектурное правило транскодирования

1. **Универсальность под любой ПК (Auto-Fallback):**
   - Никакой привязки к конкретной видеокарте или процессору.
   - При запуске транскодирования сервер пробует аппаратный ускоритель (`NVENC` или `VAAPI` с полным аппаратным декодированием `-hwaccel`).
   - Если в системе нет GPU или видеочип не поддерживает конкретный 4K/10-bit профиль, сервер автоматически и бесшовно откатывается на оптимизированный CPU-профиль (`libx264 -preset superfast -tune zerolatency -crf 23` + `flags=bilinear`).
2. **Оптимальный битрейт (стандарт Plex):**
   - 1080p: `-maxrate 8M -bufsize 16M`
   - 720p: `-maxrate 4M -bufsize 8M`
