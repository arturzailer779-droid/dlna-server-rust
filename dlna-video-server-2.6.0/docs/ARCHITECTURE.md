# Архитектура

## Слои
1. Slint UI — только представление и пользовательские команды.
2. Application Controller — жизненный цикл, оркестрация, состояние.
3. Domain/core — общие модели и события без привязки к ОС.
4. Services — библиотека, DLNA, streaming, network, compatibility, diagnostics.
5. Platform adapters — Linux/Windows.
6. Optional transcoding adapter — изолированная необязательная возможность.

## Правила зависимостей
- `core` не зависит от UI, ОС или конкретного DLNA/HTTP движка.
- `ui` не реализует сетевые протоколы и файловое сканирование.
- `dlna` получает каталог через интерфейс библиотеки, а не читает файлы самостоятельно.
- `streaming` получает разрешённый media resource от слоя библиотеки/контроллера.
- `client-compatibility` не подменяет протокольные факты догадками.
- `transcoding` не обязателен для запуска Direct Play.
- Платформенные особенности скрыты за `platform`.

## Вертикальный срез №1
Приложение запускается, отображает реальное состояние, читает/сохраняет конфигурацию и пишет журнал. Никаких фальшивых переключателей: пока функция не подключена, UI показывает её как недоступную.
